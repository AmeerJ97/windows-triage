# Support

Windows Triage is a community-maintained open-source project, not a commercial
support service. Help and response times are best-effort.

## Where to ask

- Use [GitHub Discussions](https://github.com/AmeerJ97/windows-triage/discussions) for setup questions, interpretation help, and early ideas.
- Use a bug report for reproducible application failures.
- Use a feature request for a scoped improvement with a clear user need.
- Use GitHub private vulnerability reporting for security or privacy flaws.

Search existing issues and read the [documentation](docs/README.md) before
posting. Include Windows version, tool version, scan profile, expected behavior,
actual behavior, and safe reproduction steps.

## Diagnostic data

Share `public_summary.md` in public conversations. Do not attach the full ZIP,
raw event messages, command lines, network details, or private artifacts to a
public issue. Maintainers will not ask for sensitive bundles through a public
thread.

## Scope

Windows Triage helps collect and explain PC-health evidence. It does not replace
professional hardware repair, malware response, data recovery, medical or
electrical safety advice, or Microsoft/OEM support.
